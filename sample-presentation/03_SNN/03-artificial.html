Artificial Spiking Neurons
Leaky integrate-and-fire: efficient, but hard to train
1. LIF circuit
The same RC dynamics, discretised: decay β, input WX[t], reset −θ after a spike.
→
2. Spiking network
Only neurons with U > θ fire (orange); silent ones (grey) cost no computation.
→
3. Sparse events
Binary events replace dense values: weight × spike is just a memory read.
\(\displaystyle U[t] = \beta U[t-1] + W X[t] - S_{out}[t-1]\,\theta\)
\(\displaystyle S_{out}[t] = \mathbb{1}\left[U[t] > \theta\right]\)
Hurdle: \(dS/dU\) is 0 or \(\infty\), the “dead neuron” problem. Training needs surrogate gradients.
