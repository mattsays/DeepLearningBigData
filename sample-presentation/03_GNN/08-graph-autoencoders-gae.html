Graph Autoencoders (GAE)
Learning latent node representations by reconstructing graph connectivity
ENCODER · GNN
\(\displaystyle Z=\mathrm{GNN}(X,A)\)
Inputs \(X\) and \(A\); a GNN (commonly GCN) compresses structure and features into low-dimensional embeddings \(Z\).
→
LATENT SPACE · Node embeddings
Each node is a vector \(z_i\). Embeddings capture structural similarity: related connectivity gives nearby points.
Nodes 1, 2, 3 cluster together; node 4 sits apart.
→
DECODER · Reconstruction
\(\displaystyle \hat A=\sigma(ZZ^{\top})\)
\(ZZ^{\top}\): pairwise similarity scores. \(\sigma\): sigmoid turns them into edge probabilities (darker = likelier).
Reconstruction Loss
\(\displaystyle L=-\sum_{ij}\big[A_{ij}\log\hat A_{ij}+(1-A_{ij})\log(1-\hat A_{ij})\big]\)
Compare \(\hat A\) with \(A\); optimize encoder and decoder. Binary cross-entropy, with negative sampling for missing edges.
Applications
Link prediction: estimate missing or future relationships.
Graph clustering: group nodes with similar embeddings.
GAEs learn useful graph representations by encoding nodes into a latent space and reconstructing their relationships.
