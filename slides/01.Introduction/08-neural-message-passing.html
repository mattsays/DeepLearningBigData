Neural Message Passing
Nodes learn by collecting, aggregating and updating information from their neighbors
1 · Message
Each neighbor \(u\) sends \(v\) a message from node and edge features.
\(\displaystyle m_{u\to v} = M(h_u, h_v, e_{uv})\)
\(M\): learnable message function
→
2 · Aggregation
Node \(v\) collects all neighbor messages: SUM, MEAN or MAX.
\(\displaystyle a_v = \mathrm{AGG}(\{m_{u\to v} : u\in\mathcal{N}(v)\})\)
Must be permutation-invariant
→
3 · Update
Merges \(a_v\) with the old state via a learnable MLP + activation.
\(\displaystyle h_v' = U(h_v, a_v)\)
Learns how to mix, not copy
Numerical example
identity messages · SUM
\(h_v' = \mathrm{ReLU}(0.5\,h_v + 0.2\,a_v)\)
1 {2, 3}Σ = 5h′ = 1.5
2 {1, 3}Σ = 4h′ = 1.8
3 {1, 2, 4}Σ = 7h′ = 2.9
4 {3}Σ = 3h′ = 2.6
Receptive field & stacked layers
1 layer: 1-hop neighbors
2 layers: 2 hops (1, 2 → 3 → 4)
\(K\) layers: up to \(K\) hops away
Layer 1: \(h_4 = 2.6\)
Layer 2: \(h_4=\mathrm{ReLU}(0.5\!\cdot\!2.6+0.2\!\cdot\!2.9)=1.88\)
⚠ Too many layers can cause over-smoothing: node representations become increasingly similar.
Each GNN layer expands the receptive field by one hop.
