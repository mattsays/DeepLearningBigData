Graph Convolutional Network (GCN)
Fixed, degree-based weights: the graph decides how much each neighbor counts
H(l+1)=σ(D˜−½A˜D˜−½H(l)W(l))

A GCN layer updates each node with fixed weights: the graph structure decides how much each neighbor counts, and only one matrix, W, is learned.

Self-loop. Every node also gets an edge to itself (Ã = A + I), so it keeps its own features while it listens to its neighbors.

Normalize. Each connection is weighted by 1/√(d̃i d̃j), from the degrees d̃. Well-connected nodes are damped, so hubs cannot dominate: the green neighbor, with few links, weighs the most.

Aggregate. Sum the features of the neighbors and of the node itself, each multiplied by its weight.

Transform. A learnable matrix W, shared by all nodes, and a nonlinearity σ give the new representation.
