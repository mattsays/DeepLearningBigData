Graph Representation: How GNNs See Data
Representing entities, relationships and node features
1 · What is a graph?
\(G = (V, E)\)
\(V\): set of \(N\) nodes (entities)
\(E\): set of edges (relationships)
\(X\in\mathbb{R}^{N\times F}\) node features, one row per node
\(A\in\mathbb{R}^{N\times N}\) which nodes are connected
\(D\) diagonal, \(D_{ii}\) = number of neighbors of \(i\)

3 · Why graphs?
Grids and sequences are regular; graphs encode arbitrary relationships.
Images: pixels linked to neighboring pixels
Text: tokens in a sequential chain
