GraphSAGE
Graph Sample and Aggregate: learn how to build a node's embedding from its neighborhood
hv(k)=σ(W(k)·[hv(k−1)‖AGG({hu(k−1):u∈S(v)})])

GraphSAGE does not learn one embedding per node. It learns how to build an embedding from a node's neighborhood.

Sample. Pick a fixed number of neighbors at random, here 3 of 6. The cost per node stays constant, even for hubs with thousands of neighbors.

Aggregate. Merge the sampled neighbors' vectors into a single one with an aggregator: mean, max-pooling or an LSTM.

Concatenate. Attach the aggregate to the node's own vector, so the node keeps its own information next to the neighborhood's.

Transform. A learned matrix W and a nonlinearity σ give the new embedding. W and AGG are shared by all nodes, so unseen nodes can be embedded too: GraphSAGE is inductive.
