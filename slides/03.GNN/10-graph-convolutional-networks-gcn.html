Graph Convolutional Networks (GCN)
Learning node representations through degree-normalized neighborhood aggregation
1 · The GCN layer
\(\tilde A = A + I\)
Self-loops: node keeps its own features
\(\tilde D_{ii} = \sum_j \tilde A_{ij}\)
Degrees of the self-looped graph
\(\hat A = \tilde D^{-1/2}\tilde A\,\tilde D^{-1/2}\)
Normalization: hubs cannot dominate
\(\displaystyle H^{(l+1)} = \sigma\big(\hat A\,H^{(l)}\,W^{(l)}\big)\)
\(H^{(l)}\): node representations · \(W^{(l)}\): learnable weights · \(\hat A\): normalized adjacency · \(\sigma\): activation (e.g. ReLU)
\(\hat A\) = fixed neighbor weights; the network learns \(W\).
2 · How a GCN layer works
Fixed graph-dependent weights + learnable feature transformations.
3 · Numerical example
\(\tilde d = (3,3,4,2)\)
Self (3)0.250 × 3 = 0.750
Node 10.289 × 1 = 0.289
Node 20.289 × 2 = 0.578
Node 40.354 × 4 = 1.416
Unnormalized sum: 1+2+3+4 = 10. Normalization controls the scale.
\(h_3' \approx 0.250(3)+0.289(1)+0.289(2)+0.354(4)\approx 3.03\)  (\(W=1\), identity activation)
GCN performs neighborhood aggregation using fixed degree-normalized weights and learns how to transform the resulting features.
