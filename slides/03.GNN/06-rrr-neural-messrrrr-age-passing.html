Neural Message Passing
Nodes learn by collecting, aggregating and updating information from their neighbors
= state vector of a node

Every node holds a state vector h. One round of message passing refreshes all of them in three phases: message, aggregation, update.

1Message mu→v=M(hu,hv,euv)

Every node sends a message to each of its neighbors. A learnable function M builds it from the two node states and the edge features.

2Aggregation av=AGG({mu→v:u∈N(v)})

Node 3 gathers the messages of all its neighbors into one vector, with SUM, MEAN or MAX. The result cannot depend on the order of arrival: the aggregation is permutation-invariant.

3Update hv′=U(hv,av)

Node 3 combines its old state with the aggregate through a learnable MLP and an activation. It learns how to mix the two, not just copy them.
