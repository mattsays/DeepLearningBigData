GNN Architectures
Same message passing, different ways to weight the neighbors
GCN
Graph Convolutional Network
Same weight for every neighbor

Averages the features of all neighbors, with weights fixed by the node degrees. Simple and efficient.

GraphSAGE
Graph Sample and Aggregate
3 of 6 neighbors sampled

Samples a fixed number of neighbors and aggregates only those. Scales to large graphs and handles unseen nodes.

GAT
Graph Attention Network
Learned weight α per neighbor

Learns how much each neighbor matters through attention, so the most relevant ones weigh more.
