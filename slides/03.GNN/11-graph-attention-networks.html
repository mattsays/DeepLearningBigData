Graph Attention Network (GAT)
Learn how much each neighbor matters, instead of weighting all of them the same

GAT lets the network decide which neighbors matter for each node, instead of treating all of them alike. Bars are feature vectors after the shared matrix W.

Score. A small learned function compares node i with each neighbor j, using their transformed features, and returns a score eij: how relevant is j for i?

Normalize. A softmax turns the scores into attention weights αij: positive, summing to 1. The most relevant neighbor gets the largest share, and its edge becomes thicker.

Weighted sum. Neighbor vectors are scaled by their weights, summed and passed through σ, so the result leans toward the most relevant neighbor. Multi-head attention repeats this with several sets of weights.
