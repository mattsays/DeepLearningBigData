GNN Prediction Tasks
From individual nodes to relationships and entire graphs
Node Classification
Goal: predict a class for each node.
Message passing gives embeddings; an MLP / softmax head maps each to a class.
Citation networks: paper topic. Social networks: fraudulent users.
Link Prediction
Goal: predict whether an edge exists, or its type / weight.
A scoring function evaluates pairs of node embeddings.
Social networks: friend suggestions. Recommenders: user-item interaction.
Graph Classification / Regression
Goal: predict a property of the whole graph.
READOUT / pooling merges all node embeddings, then a head predicts.
Chemistry: toxicity. Biology: protein properties.
