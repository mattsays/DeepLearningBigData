Training / Inference Procedures

Backpropagation through time (BPTT)

Follow one neuron as time advances.

t = 1: an input updates its state.

t = 2: the same neuron updates again.

t = 3: compute the output and the loss.

Open the saved history of the same neuron.

Start from the loss at the final time step.

Continue backward to the earlier moments.

Sum the contributions to the shared weights.

The state evolves. The neuron and its weights stay the same.

Save u[1] for the backward pass.

Save u[2]. Keep the same weights W.

Save u[3] and evaluate the loss.

Each view is a saved moment of neuron i, with the same weights W.

Use the surrogate derivative g(v) where the path crosses a spike.

Reuse the stored states to trace how earlier inputs affected the loss.

G = G₁ + G₂ + G₃W ← W − ηG

One update of W uses all three temporal contributions.   η: learning rate.
